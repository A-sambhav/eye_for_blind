## 1. Executive Summary

The AI architecture is built entirely around Edge Impimpulse, running on the Arduino UNO Q (ARM Cortex-M7 @ 600 MHz). Five separate neural network models handle object detection, depth processing, face recognition, text reading, and wake word detection. All inference runs on-device with no cloud dependency. Models are quantized to 8-bit integers for optimal performance on the Cortex-M7 platform with no FPU.

## 3. Inference Pipeline

### 3.1 General Inference Flow

```
Frame Capture (USB/I2S)
       │
       v
Preprocessing
  ├── Resize to model input size
  ├── Convert to grayscale (if needed)
  ├── Normalize: uint8 → int8 (0-255 → -128 to 127)
  └── Copy to inference buffer
       │
       v
Edge Impulse Runner
  ├── ei_run_classifier()
  ├── Model loads from flash to SRAM
  ├── Inference executes (quantized, int8)
  └── Output tensor returned
       │
       v
Postprocessing
  ├── Object detection: NMS, bounding boxes
  ├── Depth: disparity → distance map
  ├── Face: embedding → hash lookup
  ├── Text: CTC decode → string
  └── Wake word: threshold check
       │
       v
Publish to Message Bus
  └── MSG_OBJECT_DETECTED, MSG_OBSTACLE_ALERT, etc.
```

### 3.2 Edge Impulse Runtime Integration

```c
// ai_manager.c — Edge Impulse inference orchestration

#include <edge-impulse-sdk/classifier/ei_run_classifier.h>

// Edge Impulse signal struct (from model)
extern ei_impulse_t impulse;  // Generated by EI

static float inference_buffer[EI_CLASSIFIER_INPUT_SIZE];
static ei::signal_t signal;

void ai_manager_init(void) {
    signal.total_length = EI_CLASSIFIER_INPUT_SIZE;
    signal.get_data = &get_sample_callback;

    // Preload models into QSPI flash cache
    // Object detection model loaded on boot
    // Other models loaded on demand to save SRAM
}

int run_inference(const uint8_t* frame, ei_model_t* model, ei_impulse_result_t* result) {
    // Copy frame to quantized buffer
    memcpy(inference_buffer, frame, EI_CLASSIFIER_INPUT_SIZE);

    // Run Edge Impulse classifier
    EI_IMPULSE_ERROR res = ei_run_classifier(
        &signal,
        result,
        false  // debug = false
    );

    if (res != EI_IMPULSE_OK) {
        logger_log(LOG_ERROR, "Inference failed: %d", res);
        return -1;
    }

    return 0;
}

// Signal callback — Edge Impulse reads data through this
static int get_sample_callback(size_t offset, size_t length, float *out_ptr) {
    memcpy(out_ptr, inference_buffer + offset, length * sizeof(float));
    return 0;
}
```

### 4.2 FOMO Model Architecture

```
Input: 320×320×1 (grayscale)
    │
    v
MobileNetV2 Backbone (width multiplier = 0.35)
    ├── Conv2D (3×3, 8 filters, stride 2)           → 160×160×8
    ├── Bottleneck (t=1, c=8, s=1)                  → 160×160×8
    ├── Bottleneck (t=6, c=16, s=2)                 → 80×80×16
    ├── Bottleneck (t=6, c=16, s=1)                 → 80×80×16
    ├── Bottleneck (t=6, c=24, s=2)                 → 40×40×24
    ├── Bottleneck (t=6, c=24, s=1)                 → 40×40×24
    ├── Bottleneck (t=6, c=32, s=2)                 → 20×20×32
    ├── Bottleneck (t=6, c=32, s=1)                 → 20×20×32
    ├── Bottleneck (t=6, c=64, s=2)                 → 10×10×64
    ├── Bottleneck (t=6, c=64, s=1)                 → 10×10×64
    ├── Bottleneck (t=6, c=96, s=1)                 → 10×10×96
    └── Bottleneck (t=6, c=160, s=1)                → 10×10×160
        │
        v
FOMO Head (Depthwise separable convolutions)
    ├── Conv2D (3×3, 64, stride 1, padding=same)    → 10×10×64
    ├── Conv2D (1×1, num_anchors × (5 + num_classes)) → 10×10×(5+50)
    └── Sigmoid activation on confidence
        │
        v
Output: 10×10 grid, each cell predicts:
    - 3 anchors × (confidence, x, y, w, h, class_scores[50])
    - Total: 10×10×3×55 = 16500 values
```

### 5.2 Edge Detection for Drop-offs

```c
// depth_processor.c — Stair/curb detection algorithm

#define DEPTH_ROWS 90
#define DEPTH_COLS 160
#define EDGE_THRESHOLD_MM 150  // 15 cm drop

typedef struct {
    bool edge_detected;
    float edge_distance_m;     // Distance to edge
    float edge_width_m;        // Width of edge
    edge_type_t type;          // STAIRS_DOWN, CURB, DROP_OFF
} edge_result_t;

edge_result_t detect_drop_off(const uint16_t* depth_map) {
    edge_result_t result = {0};

    // Scan bottom half of depth map (nearest ground)
    for (int row = DEPTH_ROWS/2; row < DEPTH_ROWS - 5; row++) {
        for (int col = 5; col < DEPTH_COLS - 5; col++) {
            uint16_t d_current = depth_map[row * DEPTH_COLS + col];
            uint16_t d_below    = depth_map[(row + 5) * DEPTH_COLS + col];

            // If depth suddenly increases (pit/drop-off)
            if (d_current > 0 && d_below > 0 &&
                (d_below - d_current) > EDGE_THRESHOLD_MM) {

                result.edge_detected = true;
                result.edge_distance_m = d_current / 1000.0f;

                // Classify based on depth delta and width
                int delta = d_below - d_current;
                if (delta > 500) {  // > 50 cm drop
                    result.type = DROP_OFF;
                } else if (delta > 200) {  // 20-50 cm
                    result.type = STAIRS_DOWN;
                } else {
                    result.type = CURB;
                }

                return result;  // Return first edge found
            }
        }
    }

    return result;  // No edge
}
```

## 12. Speech Recognition

### 12.1 Wake Word Model (DS-CNN)

```
Input: 39 MFCC features × 30 time steps (300 ms audio)
    │
    v
Depthwise Separable CNN (DS-CNN)
    ├── Conv2D (3×3, 64, stride 1, depthwise)     → 39×30×64
    ├── BatchNorm + ReLU
    ├── Conv2D (1×1, 64, stride 1, pointwise)     → 39×30×64
    ├── BatchNorm + ReLU
    ├── MaxPool (2×2)                              → 19×15×64
    ├── Conv2D (3×3, 128, depthwise)               → 19×15×128
    ├── BatchNorm + ReLU
    ├── Conv2D (1×1, 128, pointwise)               → 19×15×128
    ├── BatchNorm + ReLU
    ├── MaxPool (2×2)                              → 9×7×128
    ├── Conv2D (3×3, 256, depthwise)               → 9×7×256
    ├── BatchNorm + ReLU
    ├── Global Average Pool                        → 256
    ├── Dense (64)                                 → 64
    ├── Dropout (0.5)
    └── Dense (2) → Softmax                        → 2 classes
        │
        └── "Hey Glass" / "Not Wake Word"

Model size: ~80 KB (int8 quantized)
Inference time: ~20 ms
```

### 12.2 Command Recognition Model (DS-CNN)

Same architecture as wake word but with 26 output classes (25 commands + 1 rejection).

```

Similar DS-CNN architecture with wider layers
Output: 26 classes (softmax)

```

## 14. Model Optimization

### 14.1 Optimization Techniques Applied

| Technique | Application | Benefit |
|---|---|---|
| Quantization (int8) | All models | 4× memory reduction, 3× speedup on Cortex-M7 |
| Weight pruning (30%) | Object detection | 30% size reduction, minimal accuracy loss (< 1%) |
| Depthwise separable conv | All CNN models | 7-9× fewer parameters vs standard conv |
| Input resolution reduction | Object detection | 320×320 vs 640×640 → 4× fewer operations |
| Grayscale input | Object detection | 3× fewer input channels (RGB→G) |
| FOMO detection head | Object detection | 10× faster than YOLO-based detectors |
| DS-CNN for audio | Voice models | 5× smaller than LSTM-based models |
| Model fusion | — | Run multiple outputs from single backbone (future) |

### 14.2 Edge Impulse EON Compiler

Edge Impulse uses the EON (Edge Optimized Neural) compiler, which:

- Converts trained models to highly optimized C++ code
- Eliminates runtime interpreter overhead
- Applies kernel fusion (conv + bn + relu → single operation)
- Uses int8 SIMD instructions on Cortex-M7
- Achieves 3-5× speedup over interpreted execution

## 15. Model Quantization

### 15.1 Quantization Strategy

```c
// Input quantization: uint8 → int8
// Input range: [0, 255] → [-128, 127]
// Scale = 1.0, Zero point = -128

int8_t quantize_input(uint8_t pixel) {
    return (int8_t)((int)pixel - 128);
}

// Weight quantization: float32 → int8 (per-channel)
// Weight scale and zero point stored in model metadata
// Computed during Edge Impulse training with calibration dataset

// Activation quantization: int8 (per-tensor)
// Scale factor applied after each convolution/matrix multiply

// Output dequantization: int8 → float32
// For detection: confidence = (output_int8 - zero_point) * scale
```

### 15.2 Quantization Impact

| Model | Float32 Size | Int8 Size | Accuracy Loss |
|---|---|---|---|
| Object Detection (FOMO) | 4.8 MB | 1.2 MB | -0.5% mAP |
| Depth Processing | 2.4 MB | 0.6 MB | -0.3% MAE |
| Face Recognition | 1.6 MB | 0.4 MB | -1.2% accuracy |
| Text Recognition | 2.0 MB | 0.5 MB | -0.8% CER |
| Wake Word (DS-CNN) | 0.3 MB | 0.08 MB | -0.1% accuracy |
| Command Recognition | 0.5 MB | 0.12 MB | -0.2% accuracy |

## 16. Edge AI Optimization

### 16.1 Cortex-M7 Specific Optimizations

| Optimization | Implementation | Benefit |
|---|---|---|
| SIMD (SADD8, SHADD8) | Edge Impulse EON compiler | 4-way parallel int8 operations |
| DSP extensions | ARM CMSIS-NN library usage | 3-5× matrix multiply speedup |
| Cache prefetch | Data prefetch for model weights | Reduced SRAM latency |
| Reduced precision | int8 instead of float32 | 4× memory, 3× speed |
| Loop unrolling | EON compiler optimization | Reduced loop overhead |
| Inline assembly | Critical inner loops | 2× speedup in bottleneck layers |
| Double-buffered DMA | Camera → inference buffer | Zero-copy pipeline |
| Memory pooling | Pre-allocated inference buffers | Eliminates malloc overhead |

## 19. Power Optimization

### 19.1 AI-Specific Power Management

| Strategy | Implementation | Power Saved |
|---|---|---|
| Duty-cycled inference | 15 fps instead of 30 fps | 50% AI power |
| Motion-triggered inference | Skip inference if IMU shows no head movement | Up to 80% when stationary |
| Model unloading | Unload AI model when not needed (e.g., no navigation active) | 100 mW (flash idle) |
| Frame skipping | Skip every other frame when walking slowly | 50% camera power |
| Low-power camera mode | Depth camera at 15 fps instead of 30 fps | 40% camera power |
| Audio stream gating | Only capture audio after VAD trigger | 90% audio DSP power |
| GPS power save | GPS in standby between fixes (1 Hz → 0.2 Hz when stationary) | 60% GPS power |
| WiFi sleep | ESP32 in deep sleep, wake on BLE or timer | 95% WiFi power |

## 22. Model Sizes & Recommendations

### 22.1 Recommendations

| Recommendation | Rationale |
|---|---|
| **Use FOMO (not YOLO)** for object detection | FOMO is 10× smaller than YOLOv5-nano, runs in 120 ms vs 600+ ms on Cortex-M7 |
| **Use MobileNetV2-0.35 backbone** | Best accuracy/speed trade-off for resource-constrained edge devices |
| **Use grayscale input** for object detection | Saves 3× input channels, minimal accuracy loss for depth-based detection |
| **Skip depth AI model** — use raw depth camera data | Intel RealSense D435i provides hardware-accelerated stereo matching. AI model for depth is unnecessary overhead. |
| **Use DS-CNN** for audio models | 5× smaller than LSTM, 10× faster inference, comparable accuracy |
| **Use concatenative TTS** instead of neural TTS | Neural TTS requires > 10 MB model and > 200 ms inference per word — not feasible on Cortex-M7 |
| **Load models on demand** from QSPI flash | SRAM is the tightest resource; only 1 model in SRAM at a time |
| **Run inference at 15 fps** (every other frame) | Provides 200 ms budget for full pipeline; 30 fps would require 2× compute |
| **Edge Impulse EON compiler** | 3-5× faster than TensorFlow Lite Micro, optimized for Cortex-M7 |
